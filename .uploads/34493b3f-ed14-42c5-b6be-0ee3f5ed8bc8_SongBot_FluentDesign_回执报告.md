## 二、本轮整改指令（按优先级）

### P1-1｜图标全部圆润化（必修）

现状：75 个 inline SVG 是直角硬描边，显得方正生硬。
整改：
- 全部图标改为**圆头圆拐角的线性图标**：`stroke-linecap="round"` + `stroke-linejoin="round"`；
- 统一 **24×24 视窗栅格**、**1.5px 描边**，笔画粗细一致；
- 观感对齐 Segoe Fluent Icons：柔和曲线、圆角转折，不是硬朗直角。

### P1-2｜开关组件重做（必修，这是 bug）

现状：方形外框 + 圆形把手（"外面方、里面圆"），错误。
整改（对齐 WinUI ToggleSwitch）：
- 轨道 = **跑道形胶囊**（`border-radius: 999px`，约 40×20px）；
- 把手 = **圆形**（约 12px），150ms 沿轨道滑动到另一侧；
- 关闭态：轨道 `#323232` + 1px 描边，把手灰白；
- 开启态：轨道填充 accent，把手移到右侧并变白；
- 禁止任何方形轨道。全应用所有开关统一此样式。

### P1-3｜玻璃感真正落地（必修，核心）

现状：侧边栏、播放条写了 `backdrop-filter: blur(30px) saturate(125%)`，但它们背后是纯色 `#202020`，模糊没有对象，所以视觉上**等于没有玻璃**。

整改（三件事同时做）：
1. **窗口底层铺氛围光**：在窗口最底层（`body`/根容器）加 1–2 处**极淡**的大半径径向光斑（中性蓝灰，透明度 ≤ 0.10，如 `rgba(90,130,180,.08)`）。这是 Mica 采样壁纸的近似，用来给亚克力"有东西可糊"。**不是花哨渐变，透明度必须压到几乎察觉不到。**
2. **让内容从玻璃下穿过**：侧边栏、播放条保持 `backdrop-filter: blur(30px) saturate(125%)`，确保主内容区滚动时，列表项从侧栏/播放条边缘下滚过，产生真实玻璃模糊 + 饱和度提升。
3. **Electron 原生增强（标注为打包后生效）**：主进程 `BrowserWindow` 增加 `backgroundMaterial: 'mica'`，窗口透明以透出系统壁纸。此条在网页预览里不可见，仅在打包 EXE 后生效，作为增强项保留。

验收标准：侧栏/播放条下方有内容滚过时，能明显看到玻璃模糊；窗口底层有一层若有若无的氛围色，不是死黑。

### P1-4｜去"方正生硬"，加材质层次（必修）

保持圆角 4/8/0 纪律不变，靠层次变柔：
- 卡片在现有 1px 描边基础上，**顶部加一道极淡高光**：`inset 0 1px 0 rgba(255,255,255,.04)`（WinUI 深色 elevation edge 的 catch-light）；
- 卡片 hover：背景从 `#272727` 轻微提亮 + 描边透明度从 `.07` 提至 `.10`，过渡 100ms，禁止生硬跳变；
- 标题栏、侧栏、内容区之间的过渡更柔和（描边与提亮统一节奏）。

### P1-5｜动效丰富化（必修，保留克制）

现状：几乎只有透明度变化 + 单一缓入缓出，缺乏 Fluent 的节奏与方向感。
整改，四条曲线只允许用这三条（删除其余杂牌曲线）：

```css
--ease-standard:  cubic-bezier(0.33, 0, 0.67, 1);   /* 标准 */
--ease-decelerate: cubic-bezier(0, 0, 0, 1);        /* 进入：快到慢 */
--ease-accelerate: cubic-bezier(0.7, 0, 1, 0.5);    /* 退出：慢到快 */
```

1. **页面切换带位移**：前进 = 新页从右 24px 滑入 + 淡入，旧页淡出；后退 = 镜像反向；用 `--ease-decelerate` 入场、`--ease-accelerate` 出场，280ms。禁止纯 opacity。
2. **列表 stagger 逐个入场**：队列、歌单等列表容器，子项按 `--i` 顺序延迟 `20ms/项` 逐个"淡入 + 上移 8px"，用 `--ease-decelerate`，总时长 ≤ 400ms。只在**首次进入该页**触发，滚动加载不重复。
3. **数字 count-up 跳动**：概览/弹幕互动的统计数字，用 `requestAnimationFrame` 从 0 滚动到目标值，**减速曲线（越滚越慢）**，约 800ms 完成；`prefers-reduced-motion: reduce` 时直接显示终值。
4. **连接动画保留**：FLIP 已实现，验收通过，不动。

### P2-1｜统计数字改主白色

所有统计大数字（3,842、127、4h 12m、46 等）从 accent 蓝改为**主文字色 `#FFFFFF`**。accent 只保留给：按钮、选中态、链接、状态点。数字不可点，不许用蓝。

### P2-2｜点歌台彩色标签收敛

搜索结果里"原版/现场版/翻唱/伴奏""置信 96/88"等彩色 pill 标签，统一改为**中性描边标签**：灰字 + `1px rgba(255,255,255,.1)` 描边 + 透明底。仅当**置信度低 / 需人工确认**时，才用警示色（`--warn`）。让颜色回归"有事才亮"。

### P2-3｜概览页快捷操作改命令栏

"全自动 / 清空队列 / 探测音源 / 导出歌单"四张大卡，改为**一行命令栏按钮**：图标 + 文字，hover 提亮 + 描边，紧凑一行排布。省出的垂直空间让给"正在播放"和"队列"。

## 三、交付与自查（不满足任意一条 = 未完成）

保持三文件结构与全部 JS 业务功能不变。交付前跑自查并附结果：

1. 所有 `<svg>` 图标均含 `stroke-linecap="round" stroke-linejoin="round"`；
2. 开关组件为跑道形轨道 + 圆把手，无方形轨道；
3. 窗口底层存在氛围光层，且侧栏/播放条滚动时有可见玻璃模糊；
4. 统计大数字为 `#FFFFFF`，非 accent 色；
5. 快捷操作为命令栏按钮，非大卡；
6. 动效含 stagger、count-up、带位移的页面切换；缓动曲线只有 standard/decelerate/accelerate 三条；
7. 所有动画时长 ≤ 300ms（count-up 800ms 除外），无弹簧超调、无 ripple。
