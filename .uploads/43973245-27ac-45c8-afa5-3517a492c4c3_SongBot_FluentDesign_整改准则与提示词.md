# SongBot · Fluent Design 重写指令

> 收件人：负责实现 SongBot 界面（index.html / styles.css / app.js）的 AI。
> 发件人：本项目 UI 设计师。
> 性质：设计评审结论 + 一次性重写指令。不是建议，是验收标准。

---

## 0. 评审结论：不合格，推倒重做

我先给结论，再给依据。你上一版实现的视觉层，**不合格，需要整体重写**。

你交付的是一个要打包成 Windows EXE 的 Electron 桌面应用，而你交出来的是**Material Design 3（Expressive）**——`styles.css` 第一行注释里你自己写的，还用了我最无法接受的那套：彩色渐变、玻璃糊脸、胶囊圆角、霓虹发光。你把一台 Windows 桌面应用做成了跑在桌面上的安卓 App，还挑了安卓体系里最聒噪的变体。

具体问题，逐条：

1. **基因错误**。Windows 应用就该长得像 Windows。你用的是 Google 的设计语言，用户打开第一眼就知道"这是网页糊的壳"。这是方向错误，不是细节问题。
2. **22 处 145° 彩色渐变**。按钮、卡片、图标、Hero 全是蓝紫/青蓝/橙粉渐变。Fluent 里渐变是零——每一处渐变都在稀释层级，因为你根本没决定"哪里最重要"，只能靠彩虹糖糊过去。
3. **65 处圆角、13 种值、999px 胶囊满天飞**。Fluent 一共两档圆角：4px 和 8px。所有东西都圆，圆就失去含义，边界感归零。
4. **16 处 backdrop-filter**，连侧边栏和底部播放条这种永久面板都在磨砂。你混淆了"Acrylic 玻璃感"和"无差别糊 blur"——前者是 Windows 的招牌质感，后者是磨砂保鲜膜。
5. **彩色发光阴影**：按钮蓝光、状态点绿光呼吸、`--el-glow` 品牌色光晕。这是 Winamp 年代的霓虹审美。Fluent 的深度语言是中性黑阴影 + 描边 + 亮度分层，元素看起来被环境光照着，而不是自己会发光。
6. **字体外链 Google Fonts**（Manrope + JetBrains Mono）。一个要打包成 EXE 的桌面应用去引 CDN 字体，断网启动界面直接退化——这是 bug，不是风格。Windows 的正确答案是系统自带的 Segoe UI。
7. **18 种字号**（10.5 / 11 / 11.5 / 12.5 / 13.5px……）。你是在用"感觉"排字。Fluent 的 Type Ramp 是四档走天下。
8. **ripple 水波纹 + spring 弹簧超调 + 720ms kineticUp + 520ms 页面切换**。ripple 是安卓的指纹签名，出现在 Windows 应用里等于穿着竞品队服上场。动效信条是快、短、不回头，不是果冻。
9. **信息架构照抄 AI 仪表盘模板**：10 项平铺导航、6 张等权统计卡、同一个播放状态在标题栏/侧边栏/整页出现三处、"设计规范"混进业务导航。我的主播用户最需要看的是当前播放和队列，你的层级恰好把它做得最不重要。

一句话：你生成的是训练数据的平均值——渐变、玻璃、大圆角、重阴影、卡片汤，AI 泔水美学的全套签名。**决定，才有设计；你没有做任何决定。**

下面是我替你做好的决定。逐条执行，不许变通。

## 1. 唯一目标：Microsoft Fluent Design（Fluent 2 / WinUI 3 / Windows 11）

不接受任何其他风格。所有视觉决策以 Fluent 2 规范为准，落到下面这些 token 上。

---

## 2. 颜色

- 深色主题分层底色：**层0 `#202020`（窗口基底层）→ 层1 `#272727`（卡片/面板）→ 层2 `#323232`（悬浮/hover）**。删除近纯黑的 `#06080C`。
- 文字：主 `#FFFFFF`、次 `rgba(255,255,255,.786)`（≈#C7C7C7）、三级 `#9D9D9D`；正文对比度 ≥ 4.5:1（WCAG AA）。
- **强调色只留一个**。品牌蓝校正为 Fluent 蓝 `#4CC2FF`（深色主题 accent，Windows 11 亮蓝系）；语义色仅 `ok / warn / err` 三个，只用于状态点、图标、文字，禁止大面积填充。
- **渐变政策：全项目 0 处** `linear/radial/conic-gradient`（数据图表的面积填充淡化除外）。主按钮 = 纯色 accent 填充 + 黑色文字，hover 加深 5%，pressed 加深 10%。

---

## 3. 字体与字号

- UI 字体：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", system-ui, sans-serif`。
- 等宽（时间码 / pid / 日志）：`"Cascadia Mono", "Cascadia Code", Consolas, monospace`。
- **删除所有外链字体与 `<link>`**，零 CDN 依赖。
- 字号收敛为四档，权重只用 400 / 600，`letter-spacing: 0`：

| Token | 值 | 权重 | 用途 |
|---|---|---|---|
| Caption | 12px | 400 | 辅助说明、角标 |
| Body | 14px | 400 | 正文、列表、表格 |
| Body Strong | 14px | 600 | 强调正文 |
| Subtitle | 20px | 600 | 卡片标题、区块标题 |
| Title | 28px | 600 | 页面标题、主指标数字 |

层级感靠 Segoe UI Variable 的光学尺寸轴，不靠加字距、不靠字号碎片化。

---

## 4. 圆角（只有两档，无第三种）

| Token | 值 | 用途 |
|---|---|---|
| `--radius-control` | **4px** | 按钮、输入框、列表项、卡片等页内一切控件 |
| `--radius-overlay` | **8px** | Flyout、Dialog、Tooltip、浮层 |
| 0 | 0 | 与窗口边缘相接的面板（标题栏、侧边栏贴边处） |

删除所有 `999px` 胶囊、`50%` 大圆（头像/状态点等天然圆形除外）以及 12 / 16 / 20 / 28px 全部圆角。

---

## 5. 材质：把"玻璃感"做对，而不是糊一脸

这是你上一版最该改、也最该留的地方。你要的"Windows 玻璃感"是 **Acrylic（亚克力）**，它的高级感来自**高透明度低对比 + 大半径模糊 + 饱和度提升 + 边缘描边**，不是 `blur(10px)` 那种半吊子磨砂。Fluent 的材质分三层，各司其职：

| 材质 | 层级 | 正确用法 | 本项目落法 |
|---|---|---|---|
| **Mica（云母）** | 窗口基底层 | 采样桌面壁纸着色，**不模糊**，省电 | 实色近似 `#202020`；若 Electron 窗口支持 `backgroundMaterial: 'mica'` 则原生启用 |
| **Acrylic（亚克力）** | 瞬态/品牌玻璃层 | 半透明 + 高斯模糊 + 噪点 + 饱和度 | 见下，**保留并做足参数** |
| **Smoke（烟雾）** | 模态遮罩 | 半透明黑，压暗下层 | Dialog 背后的遮罩用 `rgba(0,0,0,.4)` |

**Acrylic 允许出现的位置（玻璃感保留区）：**

- 右键菜单、Flyout、CommandBar 下拉、Dialog（弹层本体）；
- **侧边栏、底部播放条**——这是 Windows 11 常见的"半透明侧栏"质感，允许保留并作为品牌玻璃层。

**Acrylic 正确参数（照抄）：**

```css
--acrylic: rgba(44, 44, 44, .72);
backdrop-filter: blur(30px) saturate(125%);
-webkit-backdrop-filter: blur(30px) saturate(125%);
border: 1px solid rgba(255, 255, 255, .08);
```

**Acrylic 禁止出现的位置：**

- 正文卡片区、统计卡、表格、列表、任何承载大量文字的内容面板。这些必须实色 `#272727` + 1px 描边，否则对比度崩、性能崩。

**全文件 `backdrop-filter` 上限：≤ 5 处**，只允许出现在上面列出的浮层/侧栏/播放条上。删除其余所有磨砂。

---

## 6. 阴影与深度

- 深度靠**背景亮度分层 + 1px 描边**，不靠发光。
- 卡片：`inset 0 0 0 1px rgba(255,255,255,.07)`，hover 描边提亮至 `.10`。
- 仅浮层允许中性黑阴影（如 `0 8px 16px rgba(0,0,0,.26)`）。
- **禁止一切彩色阴影/发光**：删除 `--el-glow`、按钮 glow、状态点 glow 与 `pulse` 呼吸光。状态用色点 + 文字表达。

---

## 7. 图标与控件

- 图标统一用 **Segoe Fluent Icons**（`font-family: "Segoe Fluent Icons"`，16 / 20 / 24px 三档），替换现有混排图标；触达不到系统字体时，用统一栅格、统一 1.5px 描边的线性图标兜底。
- 控件高度统一 **32px**。
- 焦点态：2px 黑/白外环 + 1px 反色内环（WinUI 焦点环），**不用强调色描焦点**。
- 输入框聚焦：底边 2px 强调色下划线 + 填充提亮。
- 选中列表行：中性灰底 + 左缘 3×16px 强调色竖条。
- 每屏一个主按钮；所有可交互元素必须有 hover / focus / pressed 态。

---

## 8. 动效

| 项目 | 规范 | 删除 |
|---|---|---|
| 时长 | 微交互 100ms · 标准反馈 150ms · 浮层 250ms · **页面切换 250–300ms** | 520 / 620 / 720ms |
| 缓动 | 进入 `cubic-bezier(0,0,0,1)` · 退出 `cubic-bezier(0.7,0,1,0.5)` · 标准 `cubic-bezier(0.33,0,0.67,1)` | `--spring` / `spring-soft` 超调 |
| 按压反馈 | 背景变暗（150ms），**无波纹** | `ripple` |
| 循环动画 | 仅播放均衡器条、进行中 spinner | `pulse` 呼吸光、`wave` 装饰 |
| 入场 | 页内元素淡入 + 8px 上移，总时长 ≤ 400ms | 长队伍 stagger 逐个蹦 |
| 无障碍 | `prefers-reduced-motion: reduce` 时全部动效归零 | —（现有实现保留） |

---

## 9. 页面与页面切换

- **页面切换 = Frame.Navigate 心智**：chrome（标题栏、侧边栏、播放条）纹丝不动，只有内容区换页。
- 前进：新页从右 24px 滑入 + 淡入，旧页淡出；后退：镜像反向；同级切换：仅淡入。全程 250–300ms，标准/减速曲线，无弹跳。
- **Connected Animation**：点歌队列歌曲 → 播放详情，封面元素做"同一元素从 A 飞到 B"的连续动画（Electron 中用 FLIP 实现，300ms 减速曲线）。这是 Fluent 的招牌深度语言，比十处渐变都值钱，必须做。
- 导航选中指示器改为 WinUI 模式：3px 强调色竖条 + 中性底，150ms 标准曲线滑动，不做弹簧超调。

---

## 10. 信息架构（授权重构，业务功能一个不少）

弹幕点歌、跨源搜索、队列持久化、10030 退避、音源管理、日志——**全部保留，一个功能都不能丢**。但结构按 Fluent 导航哲学重排：

1. 侧边栏收敛为 **5–6 项**：`概览 / 点歌台 / 播放队列 / 音源与设置 / 日志`；"设计规范"移出导航（折叠进设置或删除）；用 NavigationView 式分组标题切分层级；角标只保留需要行动的状态（冲突 / 错误）。
2. 概览页建立**主视觉层级**：当前播放 + 队列状态做核心主区，四张统计卡降级为次要行/紧凑卡，"实时态势"图表缩小或折叠。**一主多次，禁止六卡等权**。
3. 删除独立"播放中心"页，改为**点击底部播放条弹出的 Acrylic 浮层**；同一播放状态只呈现一处。
4. 标题栏按 WinUI 规范与侧边栏同底色连成一体（Mica 一体化），左侧导航/返回，右侧窗口控制。

## 11. 交付与自查（不满足任意一条 = 未完成）

保持三文件结构（index.html + styles.css + app.js）与全部现有 JS 功能，只动视觉与结构。交付前跑自查并附结果：

1. `grep -c "gradient" styles.css` ≤ 1（仅图表填充）；
2. `grep -c "backdrop-filter" styles.css` ≤ 5，且只出现于浮层/侧栏/播放条；
3. 圆角无 `999px`、无 `28px`、无 `20px`，只允许 4px / 8px / 0；
4. `box-shadow` 不含任何品牌色/彩色 rgba；
5. 字号只含 12 / 14 / 20 / 28px，权重只含 400 / 600；
6. 无 ripple、无 spring、无 >300ms 动画；
7. **零 CDN 外链**：字体、图标、脚本全部本地或系统字体。
